## 设计模板

主体及数量 + 所处场景 + 空间关系/动作 + 自洽的时间和光线 + 可见材质 + 构图与视角。

真实感评价建议：主体有没有漏画/多画；几何是否合理；阴影与反光是否自洽；纹理是否过度光滑；是否出现不合场景的细节。

## 解释边界

多项提示词同时修改只能评价整组修改的效果，不能证明其中某个词有效。
如果同时改变语言、主体和构图，不能把改善全部归因于英文，也不能凭两次结果推断训练语料组成。
不要预设 v3 一定更好；最终可选择 v1 或 v2，并说明真实理由。
纯文本生成一个“类似校园”的场景，不证明它与福州大学真实建筑一致；标注 AI 生成。
