## 输出文件对应关系

运行后 outputs/ 中的 <本地编号>.png、<本地编号>.json，与 logs/calls.jsonl 中相同编号的记录对应。
JSON 中 model、provider、requested_parameters、elapsed_seconds、actual_size、image_sha256 用于核对。
SHA-256 可校验文件一致性，不是由平台签发的真实性证明。

## 上传前

把选中的真实图片、相应 JSON 和必要日志片段复制到 evidence/，核对没有个人隐私再提交仓库。
日志默认被 .gitignore 忽略；不要用 git add -f 上传整个 outputs/、logs/ 或 .env。
不要把 tests/ 的模拟返回当作真实调用。截图不宜过度压缩；大段代码改用 Markdown 代码块而不是文字截图。
